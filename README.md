# Anugerah Computer

Selamat datang di proyek **Anugerah Computer**. Proyek ini adalah aplikasi web untuk manajemen dan layanan komputer.

## Fitur Utama

- Manajemen data komputer
- Sistem inventaris
- Laporan dan analisis
- Antarmuka yang user-friendly

## Teknologi yang Digunakan

- PHP/Laravel (Backend)
- MySQL (Database)
- HTML/CSS/JavaScript (Frontend)

## Instalasi

1. Clone repositori ini
```bash
git clone <repository-url>
```

2. Install dependencies
```bash
composer install
npm install
```

3. Konfigurasi environment
```bash
cp .env.example .env
php artisan key:generate
```

4. Setup database
```bash
php artisan migrate
php artisan seed
```

5. Jalankan server
```bash
php artisan serve
```

## Penggunaan

Akses aplikasi melalui browser di `http://localhost:8000`
